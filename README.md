# Видео- и аудиосвязь «врач — пациент»

Небольшая система для видеозвонка между врачом и пациентом в локальной сети (например, три компьютера в одной Wi-Fi сети: сервер, врач, пациент). Видео и звук передаются напрямую между клиентами по WebRTC. Сервер нужен только для входа по токену и обмена служебными данными для установки соединения.

Дополнительно клиенты анализируют видео собеседника и показывают, есть ли в кадре лицо.

## Возможности

- двусторонняя видео- и аудиосвязь (WebRTC, `aiortc`)
- вход по токенам: отдельный токен для врача и для пациента
- определение лица в кадре: зелёная рамка и надпись `FACE: YES` / `FACE: NO`
- сообщения в терминале, когда лицо появилось или пропало
- необязательная озвучка этих сообщений (`--voice`)
- диагностика в терминале: уровень звука, число принятых кадров, работа детектора лиц

## Файлы

| Файл | Назначение |
|---|---|
| `doctor.py` | клиент врача |
| `patient.py` | клиент пациента |
| `call_common.py` | общий код: камера, микрофон, воспроизведение, окно видео, подключение |
| `face_check.py` | определение лица (YuNet, запасной вариант — каскады Хаара) |

Файлы `call_common.py` и `face_check.py` должны лежать в одной папке с `doctor.py` / `patient.py`.

## Установка

Нужен Python 3.9+.

```bash
pip install aiohttp aiortc opencv-python sounddevice numpy
# необязательно, для озвучки:
pip install pyttsx3
```

## Запуск

1. На одном из компьютеров запустите сервер. Он напечатает токены врача и пациента.
2. На компьютере врача:
   ```bash
   python doctor.py --server http://192.168.1.10:8080
   ```
3. На компьютере пациента:
   ```bash
   python patient.py --server http://192.168.1.10:8080
   ```

Адрес сервера замените на свой. Токен вводится в терминале (или передаётся через `--token`). Выход: клавиша `q` в окне видео или `Ctrl+C`.

## Параметры клиентов

| Параметр | Описание |
|---|---|
| `--server` | адрес сервера |
| `--token` | токен (если не указан, спросит в терминале) |
| `--camera` | номер камеры (по умолчанию 0) |
| `--mic`, `--speaker` | микрофон и динамик: номер или часть названия |
| `--list-devices` | показать аудиоустройства и выйти |
| `--width`, `--height` | размер кадра (по умолчанию 640×480) |
| `--wait` | максимальное ожидание собеседника, сек |
| `--no-face` | отключить определение лица |
| `--voice` | озвучивать появление и пропажу лица |
| `--quiet` | не печатать диагностику |

## Определение лица

Анализ идёт в отдельном потоке и не тормозит видео. Основной детектор — YuNet из OpenCV. При первом запуске он один раз скачивает файл модели (около 230 КБ) в папку со скриптами. Если скачать не удалось или версия OpenCV старая, используются каскады Хаара.

Проверить определение лица на своей камере без звонка:

```bash
python face_check.py
```

## Если что-то не работает

- **Нет звука:** запустите `--list-devices` и укажите нужные `--mic` и `--speaker`. Проверьте, что терминалу разрешён доступ к микрофону.
- **Лицо не определяется:** посмотрите в терминале строки `[видео]` и `[лицо]`. Они показывают, приходит ли видео и работает ли детектор.
- **Нет соединения:** убедитесь, что все компьютеры в одной сети и брандмауэр не блокирует порт сервера и UDP-трафик.
